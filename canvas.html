La etiqueta <canvas>

El elemento <canvas> es una superficie rectangular de píxeles dentro de la página sobre la que se dibuja con JavaScript. Es la base sobre la que p5.js crea sus dibujos.

¿Qué es <canvas>?

Un <canvas> (“lienzo”) es una etiqueta de HTML5 que reserva un área de la página. Por sí sola no muestra nada: es un lienzo en blanco transparente. Para dibujar hay que pedirle a JavaScript un contexto de renderizado, que es el objeto con los “pinceles” (métodos y propiedades) para pintar sobre él.

Un canvas es un mapa de bits (una cuadrícula de píxeles). Eso significa que, una vez pintado, el navegador no recuerda “aquí hay un círculo”: solo recuerda los colores de los píxeles. Si quieres mover el círculo, debes borrar y volver a dibujar. Esto contrasta con SVG, donde cada forma sigue siendo un objeto del documento.

Cómo se usa

Se necesitan tres pasos: poner la etiqueta, obtener el contexto y llamar a los métodos de dibujo.

<canvas id="lienzo" width="400" height="300">
  Tu navegador no admite canvas.
</canvas>

<script>
  const canvas = document.getElementById('lienzo');
  const ctx = canvas.getContext('2d');   // contexto de renderizado 2D

  ctx.fillStyle = 'tomato';
  ctx.fillRect(50, 40, 120, 80);         // x, y, ancho, alto
</script>
  • Atributos width y height: definen la resolución real del mapa de bits (si no se escriben, el canvas mide 300 × 150 píxeles). Si se cambia el tamaño solo con CSS, el dibujo se estira o se deforma, porque CSS escala la imagen, no la resolución.
  • Contenido entre las etiquetas: es el contenido alternativo. Se muestra solo si el navegador no soporta canvas y, junto con role="img" y aria-label, ayuda a la accesibilidad.
  • getContext(): devuelve el contexto del tipo pedido. Un canvas solo puede tener un tipo de contexto: después de pedir '2d', pedir 'webgl' sobre el mismo canvas devuelve null.

El contexto 2D

El contexto 2D es de modo inmediato: cada llamada pinta al instante sobre el mapa de bits. Combina dos cosas:

  • Métodos que dibujan o cambian el estado (fillRect(), arc(), translate()…).
  • Propiedades de estado que afectan a lo que se dibuja después (fillStyle, lineWidth, font…).

Al obtener el contexto se pueden pasar opciones, por ejemplo canvas.getContext('2d', { alpha: false }) para indicar que el fondo siempre será opaco.

Sistema de coordenadas

El origen (0, 0) está en la esquina superior izquierda. La x crece hacia la derecha y la y crece hacia abajo (al revés que en matemáticas). Los ángulos se miden en radianes: 0 apunta hacia la derecha y los valores positivos giran en el sentido de las manecillas del reloj. Una vuelta completa es Math.PI * 2.

Formas y trazados

Rectángulos

Son las únicas formas que se dibujan con una sola llamada: fillRect(x, y, ancho, alto) (relleno), strokeRect() (solo borde) y clearRect() (borra un área dejándola transparente).

Trazados (paths)

Todo lo demás se construye describiendo un camino y después pintándolo:

ctx.beginPath();            // empieza un trazado nuevo
ctx.moveTo(100, 20);        // coloca el "lápiz" sin dibujar
ctx.lineTo(160, 120);       // línea recta
ctx.lineTo(40, 120);
ctx.closePath();            // cierra volviendo al inicio
ctx.fill();                 // rellena el trazado
ctx.stroke();               // dibuja su contorno

ctx.beginPath();
ctx.arc(250, 70, 40, 0, Math.PI * 2);   // x, y, radio, ángulo inicial, ángulo final
ctx.fill();

Otros métodos de trazado: rect(), ellipse(), quadraticCurveTo(), bezierCurveTo() y clip(). Olvidar beginPath() es un error muy común: los trazados anteriores se vuelven a pintar junto con los nuevos.

Imágenes y píxeles

drawImage() dibuja una imagen o incluso otro canvas, y getImageData() / putImageData() permiten leer y modificar píxeles uno por uno.

Texto

ctx.font = 'bold 24px sans-serif';
ctx.textAlign = 'center';        // alineación horizontal
ctx.textBaseline = 'middle';     // alineación vertical
ctx.fillText('Hola', 200, 150);  // texto, x, y

strokeText() dibuja solo el contorno y measureText() devuelve el ancho que ocupará un texto.

Estado y transformaciones

Las transformaciones translate(x, y), rotate(radianes) y scale(sx, sy) cambian el sistema de coordenadas para todo lo que se dibuje después. Como se acumulan, se envuelven entre save() y restore(), que guardan y recuperan el estado completo del contexto (estilos y transformaciones).

ctx.save();
ctx.translate(200, 150);    // el origen ahora está en el centro
ctx.rotate(Math.PI / 4);    // gira 45°
ctx.fillRect(-40, -40, 80, 80);   // un cuadrado centrado y girado
ctx.restore();              // todo vuelve a como estaba

Animación

Un canvas no se anima solo: se repite un ciclo de actualizar → borrar → dibujar. El navegador ofrece requestAnimationFrame(), que ejecuta una función justo antes de pintar el siguiente cuadro de pantalla (normalmente unas 60 veces por segundo) y se pausa cuando la pestaña no está visible.

function cuadro() {
  x += 2;                                      // 1. actualizar
  ctx.clearRect(0, 0, canvas.width, canvas.height);  // 2. borrar
  ctx.fillRect(x, 100, 40, 40);                // 3. dibujar
  requestAnimationFrame(cuadro);               // pedir el siguiente cuadro
}
cuadro();

Eventos y posición del mouse

El canvas es un elemento más, así que recibe eventos como mousemove o click. Hay que convertir las coordenadas de la ventana a coordenadas del canvas:

canvas.addEventListener('mousemove', (e) => {
  const caja = canvas.getBoundingClientRect();
  const x = (e.clientX - caja.left) * (canvas.width / caja.width);
  const y = (e.clientY - caja.top) * (canvas.height / caja.height);
});

El factor canvas.width / caja.width corrige el caso en que CSS haya cambiado el tamaño visible del canvas.

Buenas prácticas

  • Define siempre width y height como atributos y no solo con CSS.
  • En pantallas de alta densidad (retina) el dibujo se ve borroso. Se corrige multiplicando el tamaño interno por window.devicePixelRatio y escalando el contexto.
  • Llama a beginPath() al iniciar cada figura nueva.
  • Usa save() y restore() alrededor de las transformaciones.
  • Agrega role="img" y aria-label (o contenido alternativo) para lectores de pantalla: el contenido de un canvas no es accesible por sí mismo.
  • Para animar, prefiere requestAnimationFrame() a setInterval().
