Fundamentos de p5.js

p5.js es una librería de JavaScript para crear dibujos, animaciones e interacciones con muy poco código. Es la que usamos en los cinco dibujos de este sitio.

¿Qué es p5.js?

p5.js es una librería de código abierto para “programación creativa”. Se inspira en Processing, el lenguaje pensado para enseñar programación a través de dibujos, y lo lleva a la web: funciona en cualquier navegador sin instalar nada. Su filosofía es que dibujar con código sea accesible para estudiantes, artistas y principiantes.

El simulador de Khan Academy se basa en las mismas ideas de Processing (formas, color, draw repetido), así que los dibujos se adaptan con pocos cambios. Lo que cambia es que ahora escribimos el código en archivos propios y lo ejecutamos en una página web real.

Cómo se incluye en una página

p5.js se carga con una etiqueta <script> antes del código del dibujo. Se puede usar una CDN (como en este sitio) o descargar el archivo p5.min.js:

<div id="lienzo"></div>

<script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.9.4/p5.min.js"></script>
<script src="js/sketches/rana.js"></script>

El orden importa: primero la librería y después tu código, porque tu código usa funciones que la librería define.

Estructura de un programa: setup() y draw()

Un programa de p5.js (llamado sketch) se organiza alrededor de dos funciones que p5.js llama automáticamente:

  • setup(): se ejecuta una sola vez al empezar. Aquí se crea el lienzo con createCanvas(ancho, alto) y se preparan variables.
  • draw(): se ejecuta una y otra vez, normalmente unas 60 veces por segundo (puede cambiarse con frameRate()). Cada ejecución es un cuadro de la animación.
let x = 0;

function setup() {
  createCanvas(400, 400);      // se ejecuta una vez
}

function draw() {
  background(220);             // borra el cuadro anterior
  circle(x, 200, 50);          // dibuja
  x = x + 2;                   // cambia el estado para el próximo cuadro
}

La variable frameCount cuenta los cuadros dibujados desde el inicio y es muy útil para animaciones basadas en tiempo. Para que el dibujo no se repita, se puede usar noLoop().

Las coordenadas funcionan igual que en canvas: origen arriba a la izquierda, y crece hacia abajo. Por defecto los ángulos están en radianes (angleMode(DEGREES) los cambia a grados).

Color y estilo

p5.js recuerda el estilo actual y lo aplica a todo lo que se dibuje después:

background(135, 206, 235);     // fondo con RGB (rojo, verde, azul: de 0 a 255)
fill(255, 200, 0);             // relleno amarillo
stroke(0);                     // contorno negro (un solo número = gris)
strokeWeight(3);               // grosor del contorno
circle(200, 200, 100);

noStroke();                    // sin contorno
fill(255, 0, 0, 120);          // el 4.º número es la transparencia (alfa)
rect(150, 150, 100, 100);
  • noFill() y noStroke() desactivan relleno y contorno.
  • colorMode(HSB) cambia a tono, saturación y brillo.
  • lerpColor(c1, c2, t) mezcla dos colores: es la base de los degradados del dibujo del día nevado.

Interacción: mouse y teclado

Variables del sistema que p5.js actualiza solas: mouseX, mouseY (posición actual), pmouseX, pmouseY (posición en el cuadro anterior), mouseIsPressed, key, keyIsPressed, width, height y frameCount.

Funciones de evento que p5.js llama cuando ocurre algo: mousePressed(), mouseReleased(), mouseMoved(), mouseDragged(), keyPressed().

function mousePressed() {
  // se ejecuta una vez cada vez que se hace clic
  conSombrero = !conSombrero;
}

function keyPressed() {
  if (key === '1') bufanda = [220, 50, 60];   // tecla "1"
}

Estas funciones se activan con eventos de toda la página, no solo del lienzo. Por eso en los dibujos se comprueba que el mouse esté dentro del lienzo antes de reaccionar.

Transformaciones: translate, rotate, scale, push y pop

translate(x, y) mueve el origen, rotate(ángulo) gira el sistema de coordenadas y scale(s) lo agranda o reduce. Se acumulan, así que se encierran entre push() (guarda el estado) y pop() (lo recupera). Es lo mismo que save() y restore() del canvas nativo.

push();
translate(200, 200);        // el origen pasa al centro
rotate(frameCount * 0.02);  // gira un poco más en cada cuadro
rect(-40, -10, 80, 20);     // una barra centrada en el origen
pop();

Modo global y modo instancia

En el modo global, el que usamos aquí, las funciones de p5.js (circle, fill…) y las variables (mouseX…) están disponibles directamente. Es lo más sencillo para empezar, pero solo admite un sketch por página y llena el espacio global de nombres.

En el modo instancia se crea un objeto p5 y todo se llama a través de él, lo que permite varios sketches en una misma página:

const mi = new p5((p) => {
  p.setup = () => p.createCanvas(200, 200);
  p.draw = () => {
    p.background(240);
    p.circle(p.mouseX, p.mouseY, 40);
  };
}, document.getElementById('lienzo'));

Cómo se relaciona p5.js con <canvas>

createCanvas() inserta un elemento <canvas> en la página, y p5.js dibuja en su contexto 2D con los métodos que vimos en la página sobre canvas: las formas se pintan con métodos del contexto 2D (como arc() o ellipse() y fill()), y push() / pop() cumplen un papel parecido a save() / restore(). El contexto nativo está disponible en la variable drawingContext, por si quieres usar algo que p5.js no ofrece (como un degradado):

function setup() {
  createCanvas(300, 200);
  const g = drawingContext.createLinearGradient(0, 0, 300, 0);
  g.addColorStop(0, 'orange');
  g.addColorStop(1, 'purple');
  drawingContext.fillStyle = g;
  rect(0, 0, 300, 200);
}

Con createCanvas(ancho, alto, WEBGL) p5.js usa el contexto WebGL en lugar del 2D para dibujar en 3D. Además, .parent('lienzo') permite colocar el lienzo dentro de un elemento concreto de la página, como se hace en todos los dibujos de este sitio.
