Inspector del DOM

El DOM (Document Object Model) es el árbol de elementos que el navegador construye a partir del HTML. Aquí puedes ver, de forma gráfica, el árbol de cada página de este sitio: desde la raíz <html>, pasando por <head> y <body>, los contenedores semánticos como <header> y <main>, hasta los elementos hijos como <h1>, <p> o <canvas>.

Cómo leerlo

  • Cada caja es un elemento (etiqueta). El texto después de # es su id y después de . sus clases.
  • La línea que sale hacia la derecha lleva a sus hijos; el número dentro de la caja indica cuántos tiene.
  • Haz clic en una caja con hijos para contraer o expandir esa rama (queda con un borde naranja cuando está contraída).
  • Los <canvas> de los dibujos aparecen porque p5.js los crea con JavaScript al cargar la página: el inspector lee el DOM ya construido, no solo el archivo HTML.

Este inspector carga cada página en segundo plano, así que funciona desde GitHub Pages o un servidor local, pero no abriendo el archivo con doble clic.
