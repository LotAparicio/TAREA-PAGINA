Dientes de conejo

Un conejo con sus característicos dientes frontales. Haz clic para que muerda la zanahoria hasta acabársela.

Cómo interactuar

  • Clic dentro del lienzo: el conejo da una mordida y salen migajas.
  • Cuando se acaba la zanahoria, otro clic trae una nueva.
  • Mueve el mouse: los ojos lo siguen.

Conceptos de p5.js que se usan

  • push(), translate() y rotate() para colocar las dos orejas con un mismo código (lado = -1 y 1).
  • rect() con esquinas redondeadas para los dientes y triangle() para nariz y zanahoria.
  • map() para que la zanahoria se adelgace al acortarse.
  • Un arreglo de objetos (migajas) con velocidad y gravedad: un sistema de partículas básico.
  • sin() para abrir la boca y hacer vibrar los dientes durante la mordida.
